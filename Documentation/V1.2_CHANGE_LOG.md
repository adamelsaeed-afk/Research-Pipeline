**1. Unambiguous, bounded input decoding.** New `scripts/strict_json.py` rejects
duplicate object members at every nesting level, NaN/Infinity and overflowing
floating-point values. JSON contracts have a 4 MiB UTF-8 limit and 64-level nesting
limit. Bounded text reads retain exact newline bytes when hashing. The intake
checker, dispatcher, preflight, mailbox and manual probe use these helpers for
their JSON inputs; role JSON and Antigravity envelopes use the same strict decoder.
The intake hash-preview route is bounded too. Repeated keys cannot silently replace
an earlier verdict, claim list or configuration member. Errors do not echo member
values. This implements stricter behavior than Python's permissive JSON defaults;
see the [Python JSON documentation](https://docs.python.org/3/library/json.html).

**2. Source probe success.** `tests/manual_live_dispatch.py` now requires a confirmed
